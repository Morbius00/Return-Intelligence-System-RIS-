📊 System Overview

This production-ready NLP system analyzes customer feedback using classical machine learning (TF-IDF + Logistic Regression). It detects spam, assigns Severity Scores for negative feedback and Goodwill Scores for positive feedback, and provides fast, explainable predictions.

API Base URL: http://localhost:8000
Processing Time: <50ms per request
Model Type: Dual TF-IDF + Logistic Regression (Negative & Positive sub-models)
